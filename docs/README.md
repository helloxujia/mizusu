## What

MizuSU is a third-party fork of KernelSU with a redesigned UI, built-in toolbox, and one-click config presets. Kernel functionality is untouched.

- **Theme** — Dual theme (Miuix / Material 3), 8 icon packs, glass blur, startup sounds
- **Toolbox** — Built-in Zako Toolbox for device checks, module management, app disguise
- **One-click Config** — Common hide presets, SELinux, SuSFS — ready out of the box

## Download

[Releases](https://github.com/helloxujia/mizusu/releases)

## Build

```bash
git clone https://github.com/helloxujia/mizusu.git
cd mizusu/manager
./gradlew assembleDebug
```

## Disclaimer

This fork is for learning. Kernel features are identical to official KernelSU.
